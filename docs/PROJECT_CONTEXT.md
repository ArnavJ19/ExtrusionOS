# Project Context — ExtrusionOS

## 1. Product Overview

ExtrusionOS is a vertical SaaS platform for aluminium extrusion MSMEs and aluminium systems businesses in India.

It is designed for companies that manufacture, trade, fabricate, quote, dispatch, or install aluminium profiles and aluminium door/window systems.

The product helps businesses replace fragmented workflows such as:

- Excel quotation sheets
- WhatsApp customer follow-ups
- Manual die registers
- Tally-only finance records
- Paper production registers
- Manual dispatch notes
- Scattered PDFs and drawings
- Unstructured inventory records

with a structured cloud-based operating system.

## 2. Target Customers

ExtrusionOS is built for:

- Aluminium extrusion factories
- Aluminium profile suppliers
- Aluminium systems companies
- Door/window fabricators
- Dealers and distributors
- Contractors
- Solar structure suppliers
- Industrial aluminium profile vendors
- Architecture/infrastructure vendors
- MSME manufacturers using aluminium profiles
- Companies supplying to airports, railways, metro, power, solar, buildings, and infrastructure projects

## 3. Main Users

### 3.1 Owner / Director

Needs:

- Sales visibility
- Order visibility
- Production visibility
- Dispatch visibility
- Receivables visibility
- Scrap/yield visibility
- Customer profitability
- Delayed order alerts
- Low stock alerts
- High rejection die alerts
- Overdue payment tracking
- Business dashboard

Owner cares about:

- Where money is leaking
- Which customers are profitable
- Which orders are delayed
- Which dies cause rejection
- Which inventory is stuck
- Which payments are overdue

### 3.2 Sales User

Needs:

- Create customers
- Create quotations
- Pull profile data automatically
- Use default rates
- Generate professional quotation PDFs
- Send WhatsApp-friendly summaries
- Track quote status
- Follow up on expiring quotes
- Convert approved quotes to orders

Sales user should not need to understand the full factory complexity.

### 3.3 Production User

Needs:

- View confirmed orders
- See order stages
- Plan production jobs
- See die readiness
- See billet readiness
- Update production status
- Record actual output
- Record rejection/scrap
- Track machine/press assignment

Production user needs clarity, not clutter.

### 3.4 Dispatch User

Needs:

- See orders ready for dispatch
- Track bundles
- Track weight
- Track transporter
- Track vehicle number
- Track e-way bill
- Track LR number
- Upload proof of delivery
- Mark dispatch/delivery status

Dispatch flow must reduce wrong material, wrong bundle, and missing-document mistakes.

### 3.5 Accounts User

Needs:

- Track invoices
- Track payments
- Track advance payments
- Track balance due
- Track overdue customers
- Send payment reminders
- View customer outstanding

ExtrusionOS is not necessarily a full accounting replacement, but it should provide operational receivables clarity.

### 3.6 Quality User

Needs:

- Record inspections
- Upload test certificates
- Track NCRs
- Track complaints
- Track corrective actions
- Link quality documents to orders/batches
- Maintain audit-ready documentation

### 3.7 Dealer / Customer / Portal User

Needs:

- View quotes
- View order status
- Download safe documents
- Submit quote requests
- Raise complaints/support tickets

Portal users must never see internal cost, margins, supplier rates, or other customer data.

## 4. Core Product Promise

ExtrusionOS helps aluminium businesses run sales, production, dispatch, inventory, and payments from one structured system.

The product should make the company faster, more accurate, and more transparent.

## 5. Core Business Pain Points

The product should solve these problems:

1. Quotation mistakes due to manual Excel calculations
2. No centralized customer database
3. Profile data scattered across catalogues and drawings
4. Die information stored in registers or memory
5. Orders tracked over WhatsApp and phone calls
6. Production delays not visible to management
7. Dispatch mistakes and missing documents
8. Inventory not updated in real time
9. Scrap/rejection not measured properly
10. Quality documents difficult to retrieve
11. Customer payment follow-up is manual
12. Owner cannot see business health quickly

## 6. Indian MSME Context

- INR currency

- Indian phone numbers

- E-way bill fields

## 8. Product Philosophy

ExtrusionOS should be:

- Practical before fancy
- Industry-specific before generic
- Clean before complex
- Accurate before beautiful
- Secure before fast
- Explainable before automated
- Useful for MSMEs before enterprise-heavy

Avoid building a bloated ERP.

A small factory owner should understand the value within 5 minutes of a demo.

## 9. What the Product Should Not Become

ExtrusionOS should not become:

- A generic CRM
- A generic ERP clone
- A payroll system
- A full accounting replacement unless specifically scoped
- A toy dashboard
- A UI-only prototype
- A feature dump
- A system with weak RLS
- A system that exposes customer/internal cost data incorrectly

## 10. Success Criteria

A demo should clearly show:

1. Customer database
2. Profile master
3. Die library
4. Accurate quote creation
5. Professional quote PDF
6. Quote-to-order conversion
7. Order stages
8. Production job visibility
9. Dispatch tracking
10. Inventory status
11. Payment outstanding
12. Owner dashboard
13. Security and tenant isolation

If the product cannot demonstrate these flows cleanly, prioritize fixing them before adding new features.
