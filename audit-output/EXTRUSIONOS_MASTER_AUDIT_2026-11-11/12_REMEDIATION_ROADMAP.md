# Remediation Roadmap

This is a recommendation and sequencing record. Implement each group under separate authorization and preserve existing commercial and operational history.

| Sequence | Work | Dependencies and regression evidence |
|---|---|---|
| Immediate containment | Resolve applicable Next.js and runtime dependency advisories. Confirm invitation policy, public routes, onboarding and Auth configuration on the production binding. | Audit locked and deployed versions separately. Build and rerun signed-in access, proxy and document rendering tests. Validate existing authorized owner/admin recovery before restricting bootstrap. |
| Data integrity | Enforce actual heat mass, dross, measured rejects and approved tolerance. Validate chemistry against approved specification revisions. | Establish accepted units and measurement tolerances first. Replay against representative legacy heats and preserve exceptional records with reviewed reconciliation. |
| Production-critical | Align allocation, actual issue, consumption, corrections and production completion. Bind downstream quarantine to a documented recall policy. | Validate partially issued jobs, returns and remnants, multi-lot ancestry, previously shipped descendants and concurrent job/stock updates. |
| Stock and dispatch | Make summary and readiness reads use canonical quantities. Show unknown as unavailable. Reconcile packaging and dealer stock bases, then verify bundle/transfer/dispatch boundaries. | Establish unit and owner semantics. Test partial reserve, hold, loss, damage, same-bundle replay, interrupted dispatch and net stock after reversal. |
| Commercial and finance | Correct bank direction normalization and dedupe ambiguity. Align credit exposure with the invoice basis, including unknown value. | Use sample exports for each bank, durable bank identifiers and approved matching/reversal policy. Test no-reference duplicates, overpayments, unapplied credits, two concurrent gate-outs and signed statements-to-books totals. |
| Operator usability | Restore authorized camera scanning, preserve keyboard fallback, and ensure capped summaries label scope. | Exercise shared device/tablet/phone, permission denial, keyboard/large text, double-tap and interrupted transaction on the intended release. |
| Architecture and reliability | Make all live grants, commands and jobs part of a versioned manifest. Bind release evidence to an immutable commit, lockfile and reconciled database catalog. | Keep behavioral checks alongside inventory assertions. Run native two-session and representative-volume SQL tests and review schema/API type drift. |

Signed release evidence should cover factory, stores, accounts, dispatch, quality, IT/security and approved operator acceptance. Keep unresolved legacy discrepancies separately visible until their source documents and physical balances reconcile.
