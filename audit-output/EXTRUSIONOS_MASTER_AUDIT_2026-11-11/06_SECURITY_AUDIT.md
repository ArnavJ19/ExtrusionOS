# Security Audit

**Omalco invitation-only access is unproven on the production release.** The captured app redirects public signup. The latest production deployment record points to a revision that still renders the signup form. The linked hosted catalog has the single-company insert guard and retains the authenticated onboarding grant. The grant is an exposure/control-review signal. Actual existing-company membership, provider signup settings, invitations, suspensions and alias-to-database binding need approved signed-in verification. [MFA-008](02_COMPLETE_DEFECT_REGISTER.md#mfa-008--omalco-invitation-only-policy-differs-across-layers-and-releases)

The isolated SQL role tests use synthetic identities and platform stand-ins. They do not establish hosted JWT behavior or Storage object access. Security evidence in this audit is confined to source analysis, dependency versions, catalog/advisor observations and authorized defensive tests.
