3. Communicate the new authority rules:
   - Sales roles can no longer edit dispatch rows directly or make dies usable.
   - Only managers can return a die to active or approved status.
   - A recorded e-way bill or LR number on a shipped dispatch now needs an amendment workflow, which does not exist yet.
   - Validate `machines_status_check` after confirming the live statuses. Today the only live machine is `active`.
4. Reserved-stock rate follows the order line. Shipping reserved stock is only possible when the order has exactly one line for that profile, or exactly one line whose finish matches the stock batch. Before applying, review existing open reservations whose orders have several lines for the same profile.
5. Die exclusivity applies to newly scheduled, released or started work. Existing overlapping released slots are not cancelled; check the press schedule for conflicts before applying.

   - Free-text hardness requirements (e.g. "T6 per IS 733") are not parsed.
